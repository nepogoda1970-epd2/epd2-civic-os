## Forms and Official Documents Coverage

Required of every domain PACK by `FIR-FORM-002`.

| Question                                | Answer                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Which forms are fully defined?          | All fifteen in `PACK-14-FORM-INVENTORY.md`, at specification level: fields, validation, declarations, workflow, attachments and renditions                                                                                                                                                                                                                                                                     |
| Which exist only as system models?      | None. Every identity operation in the workflow matrix has a form                                                                                                                                                                                                                                                                                                                                               |
| Which official texts are still missing? | None for the fifteen inventoried forms; `PACK-14-CONTENT-CATALOGUE-DE.md` carries real German text. Texts for future assisted-channel paper equivalents are deferred                                                                                                                                                                                                                                           |
| Which renditions exist?                 | Specified for web, mobile, accessible, print and archival PDF. **None is implemented** — this round writes no frontend                                                                                                                                                                                                                                                                                         |
| Is the page sequence defined?           | **No, and deliberately not.** `FIR-UX-011` assigns page order, navigation, screen structure and the ten page-specification artefacts to the relevant `FRONT-PACK Specification + UX/IA` stage, which must complete before frontend implementation. PACK-14 supplies the domain side: process, authoritative data, permissions and assurance per action, forms, decisions, governed content and state semantics |
| Which forms are deferred?               | Paper equivalents for the assisted and offline channels, pending `FIR-INCLUSION-001`'s own round                                                                                                                                                                                                                                                                                                               |
| Which FIR entries are addressed?        | `FIR-FORM-001` … `FIR-FORM-005` — partially addressed at specification level                                                                                                                                                                                                                                                                                                                                   |
| Does a missing form block PASS?         | Yes for the implementation round: registration, authentication, passkey enrollment, recovery and account closure cannot complete their user journeys without their forms, so their absence is a PASS blocker there. It does not block **this** round, which is specification only                                                                                                                              |
