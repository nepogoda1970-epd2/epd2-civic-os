# FRONT-01 — Public Website Scope

Status: **FRONT-01 PUBLIC WEBSITE 0.2.0 CANDIDATE**

FRONT-01 implements only **WS-01 Public Website**. It migrates public information
into the accepted FRONT-00 design system and labels every capability with a
controlled maturity state.

## Included

- 31 public, statically generated routes;
- shared public navigation, footer and `CapabilityStatusBanner`;
- public read-only program skeleton;
- explanatory initiative lifecycle, voting boundary, publication flow and
  progress-board concepts;
- migration decisions for all 61 legacy HTML files;
- accessibility, architecture, link, content and browser regression tests.

## Excluded

No login, member dashboard, eID, ballot, tally, delegation, compliance case,
legal notice, finance ledger, payment, administration console, mandate-holder
workspace, citizen-office caseflow, operational transparency-store access,
analytics, fingerprinting or cross-workspace identifier is implemented.

Future WS-02, WS-03, WS-04, WS-05 and WS-10 capabilities are explained only.
There is no eleventh workspace and no universal SPA.

Repository version remains `0.9.0`; Canon version remains `0.7.0`.
