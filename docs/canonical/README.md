# docs/canonical

Каноническая документация EPD² Civic OS.

## Действующая версия канона

**`CANON_VERSION = 0.7.0`** (`docs/canonical/canon-version.json`,
машинно-читаемый источник истины). Версии `0.5.0` и `0.6.0` **более не
действуют** — обе последовательно заменены более новыми принятыми
поправками; ни один раздел настоящей директории не описывает текущее
состояние канона как `0.5.0` или `0.6.0`.

Последняя поправка — CLAUDE-PACK-08, каноническая версия `0.6.0 →
0.7.0` (ADR-037, `accepted`, 2026-07-25): новый раздел 19e
("Организация и региональная авторизация — расширение / Organization &
Regional Scope Context"). См. `docs/adr/ADR-037-organization-and-regional-scope-canon-amendment.md`
и `docs/handover/PACK-08-CANON-AMENDMENT-REPORT.md` для полного
описания и точных результатов проверки.

## Содержимое

- `TZ-00-domain-event-canon.md` — ТЗ-00, каноническая модель домена и
  событий. Действующий архитектурный канон проекта, версия `0.7.0`.
- `canon-version.json` — машинно-читаемая версия канона и диапазон
  совместимости репозитория.
- `PACK-08-GLOSSARY.md` — терминологический справочник для раздела 19e
  (Organization & Regional Scope Context); документационный, не
  канонический текст — при расхождении раздел 19e самого канона
  первичен.

## Правило неизменности

Файл `TZ-00-domain-event-canon.md` **нельзя**:

- редактировать;
- сокращать;
- переименовывать сущности, статусы, события или reason codes в нём;
- изменять описанные архитектурные инварианты,

без отдельного задания и принятого `Architecture Decision Record` (см.
`docs/adr/`).

Любое предложение по изменению канона фиксируется в
`docs/review/OPEN_QUESTIONS.md` или оформляется как issue по шаблону
`architecture_change.yml`, но не вносится в канон самостоятельно.
